# Employee & Project Data Analysis | Python

### Project Overview
Completed a data analysis project using Python, Pandas, and Matplotlib to clean, transform, merge, and analyze employee, project, and department datasets. The project focused on workforce management, project performance, employee designations, and project cost analysis.

### Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- CSV datasets

### Tasks Performed

1. **DataFrame Creation:** Created three DataFrames and saved them as CSV files.
2. **Missing Value Treatment:** Filled missing project costs using a running average calculated with a `for` loop.
3. **Name Splitting:** Split employee names into First Name and Last Name columns.
4. **Data Integration:** Joined employee, project, and department data into a single DataFrame named `Final`.
5. **Bonus Calculation:** Calculated a 5% project-cost bonus for employees who completed their projects.
6. **Designation Updates:** Reduced designation levels for failed projects and removed records with designation levels above 4.
7. **Name Formatting:** Added appropriate titles to first names and removed the gender column.
8. **Employee Promotion:** Increased designation levels by 1 for employees older than 29 using an `if` condition.
9. **Project Cost Analysis:** Calculated the total project cost for each employee and saved the result in `TotalProjCost`.
10. **City-Based Filtering:** Retrieved employee records for cities containing the letter "o".

### Key Skills Demonstrated
- Data cleaning and preprocessing
- Missing value handling using loops
- Data merging and transformation
- Conditional logic and business rules
- Employee and project cost analysis
- Data visualization using Matplotlib
- CSV file handling and reporting

### Conclusion
This project strengthened my practical skills in Python-based data analysis and demonstrated how data transformation, conditional logic, and aggregation can support employee and project management decisions.
